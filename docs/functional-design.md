## 0. 文档约定

### 0.1 术语

| 术语 | 含义 |
|---|---|
| 工作室 Studio | 团队/组织空间，是图书、音色、资产、积分的归属单位。注册时自动创建一个个人工作室 |
| 图书 Book | 一部有声作品（一个制作项目），可以是单播有声书、多播有声书或广播剧 |
| 卷 / 章节 Chapter | 图书的组织层级。章节对应发布时的"一集" |
| 画本 Script | 章节的演播脚本：把章节拆成有序的片段，每段标注角色、情绪、注音、停顿等 |
| 片段 Segment | 画本的最小单元，即一句台词或一段旁白 |
| 音频版本 Take | 某个片段的一次音频产出。来源可以是 AI 生成、在线录音或对轨切片。一个片段可以有多个 Take，选中其中一个 |
| 角色 Character | 书中的说话人，包括旁白、主角、配角、龙套、群演 |
| 音色 Voice | 可用于合成的声音，来源有：官方预设、AI 设计、声音克隆 |
| 选角 Casting | 为角色挑选并绑定音色（AI 配音）或指定 CV（真人配音） |
| CV | 配音演员 |
| 智能对轨 | 把真人录的长音频自动切片，并匹配到画本中对应的片段 |
| 智能审听 | 自动比对音频和文稿，标出漏读、多读、错读等问题 |
| 工单 Issue | 一个需要返修的问题，定位到具体片段，有处理人和状态 |
| 生产任务 Task | 某个章节在某个工作流环节（画本 / 配音 / 后期 / 审听…）上的工作单元 |
| 积分 Credit | 平台统一的 AI 用量计量单位 |
| BYOK | 工作室自带第三方平台的密钥 |

### 0.2 优先级

| 级别 | 目标 |
|---|---|
| **P0** | MVP：一章文本能做出 AI 多播成品，具备基础账号、工作室、资产、管理端 |
| **P1** | 真人链路：在线录音、智能对轨、智能审听、工单 |
| **P2** | 生产管理：工作流派单、看板、计薪、分享审听 |
| **P3** | 规模化与增强：一键成书、开放 API、后期增强、专业克隆 |
| **P4** | 生态：多平台分发、声音市场、私有化交付 |

正文中的每个功能点都标注了优先级，例如 `[P0]`。

## 1. 产品概述

### 1.1 定位

本平台是一个以工作室协作为核心、**AI 与真人混合**的有声内容生产平台。它覆盖从书稿到成品分发的全链路：

```
书稿 → 智能拆章 → 智能画本 → 选角 → AI 配音 / 真人录音 → 对轨 → 后期 → 审听返修 → 成品 → 分发
```

### 1.2 目标用户

| 用户 | 核心诉求 | 主要使用的功能 |
|---|---|---|
| 个人创作者 / 网文作者 | 低成本把作品做成有声书，快速出 Demo | 一键成书、AI 多播、快速配音 |
| 有声工作室 / 剧组 | 做精品多播，人机混编，管理团队和成本 | 画本、选角、录音、对轨、后期、审听、派单、计薪 |
| 配音演员 CV | 高效录音，经营个人声音 | 我的台词、在线录音、个人音色、声音授权 |
| 网文平台 / 出版社 / 版权方 | 批量有声化中长尾 IP，书稿保密 | 一键成书批量、开放 API、私有化部署 |
| 平台运营 | 管理供应商、成本、内容合规 | 管理端 |

### 1.3 两条产品线

| | 精品工作台 | 全自动流水线（一键成书） |
|---|---|---|
| 面向 | 工作室、剧组、CV | 个人创作者、B 端批量客户 |
| 特点 | 每个环节都可人工把控，人机协同 | 上传即出成品，无人值守，事后精修 |
| 质量 | 精品 | 经济 / 标准 / 精品三档可选 |
| 关系 | 共用同一套数据模型。一键成书的结果可以进入精品工作台继续精修 | |

### 1.4 差异化

| 能力 | ElevenLabs | 万象有声 | 本平台 |
|---|---|---|---|
| 音色来源 | 自研模型 | 平台精调音色库 | **多平台聚合**：阿里、MiniMax、火山、ElevenLabs、自部署模型，同一本书里可以混用 |
| 成本 | 积分，约 12 元/万字（Pro 套餐粗算） | 7.9 元/万字 | **按质量档做成本路由**：旁白走低成本模型，主角走高表现力模型 |
| 自带密钥 | 无 | 未提及 | **支持 BYOK** |
| 真人链路 | 弱 | 强 | 强（对标万象有声） |
| 生产管理 | 弱 | 强 | 强（对标万象有声） |
| 部署 | SaaS | SaaS | **SaaS + 私有化**（面向版权方的书稿保密需求） |
| 声音经济 | 专业克隆音色共享分成 | 未提及 | **CV 个人音色授权与分成**（P4） |
| 发音词典 | 项目词典 | 百万级纠错字典 | 平台、工作室、图书三级词典，用户纠错众包回流到平台词典 |

| 审核员 | 内容审核、克隆授权审核、举报处理 |

### 2.2 工作室角色（管理权限）

| 角色 | 说明 |
|---|---|
| 所有者 | 唯一。拥有全部权限，包括计费、转让、解散工作室 |
| 管理员 | 成员管理、工作室设置、供应商密钥、计薪配置，可访问所有图书 |

| 外部协作者 | 只被邀请进某本图书（例如外聘 CV），看不到工作室的其他内容 `[P1]` |

## 4. 用户端功能

### 4.1 账号 `[P0]`

**注册**
- 支持邮箱或手机号注册，都需要验证码。海外版用邮箱。
- 密码至少 8 位，必须同时包含字母和数字。
- 必须勾选用户协议和隐私政策。
- 注册成功后：
  - 自动创建个人工作室。
  - 发放新人积分（数额在管理端配置）。
  - 进入新手引导：选择身份（创作者 / 工作室 / CV），推荐相应的入口。
- 第三方登录 `[P2]`：按标准 OAuth 2.0 / OpenID Connect 接入，后台可添加 GitHub、Google、Microsoft、GitLab、Gitee、微信扫码，以及任意 OIDC 或 OAuth 2.0 服务。
- 可开启"邀请制注册"（在管理端配置），开启后必须凭邀请码注册。

**登录**
- 支持密码登录和验证码登录。
- 连续失败 5 次后要求图形验证码；失败 10 次锁定 15 分钟。
- 支持"记住我"（30 天）。
- 管理端是独立的登录入口，只允许有管理员角色的账号登录。

**找回密码**：通过邮箱或手机验证码重置。重置后，所有设备上的登录会话全部失效。

**个人中心**
- 资料：头像、昵称、简介。
- CV 主页 `[P2]`：声线标签、代表作品、试音片段，供工作室挑选 CV。
- 安全：修改密码、绑定或换绑手机和邮箱、查看登录设备列表并可踢下线、注销账号。注销有 7 天冷静期，且要求名下没有尚未转让的团队工作室。
- 偏好：界面语言（中文 / 英文）、主题、通知偏好（站内信、邮件、浏览器通知，按事件类型分别开关）。
- 实名认证 `[P2]`：使用国内的声音克隆等合规功能前需要实名。

### 4.2 工作室 `[P0]`

- **创建团队工作室**：填写名称、Logo、简介。一个用户可以创建或加入多个工作室，在顶栏切换。
- **成员管理**：
  - 邀请：支持链接、邮箱、手机号三种方式，邀请时指定角色，7 天有效，可撤销。
  - 也可以设为"申请加入需审批"。
  - 可修改成员角色、移除成员、转让所有者（需要对方确认）。
  - 席位上限由套餐决定，超出时提示升级。
- **外部协作者** `[P1]`：在某本图书里直接邀请，只占用该图书的访问权限，不占工作室成员席位（是否计席位在管理端配置）。
- **工作室设置**：
  - 基本信息。
  - 默认制作参数：默认响度标准、停顿规则、导出格式、片头片尾模板。新建图书时会继承这些参数。
  - 工作流模板（见 4.15）`[P2]`。
  - 发音词典（工作室级，见 4.6.5）`[P0]`。
  - 供应商密钥 BYOK（见 4.8.6）`[P2]`。
  - 计薪单价（见 4.16）`[P2]`。
  - 计费与账单（见 4.21）。
  - 开放平台（见 4.22）`[P3]`。
- **解散工作室**：只有所有者可以操作，前提是没有进行中的任务。需要二次确认，数据保留 30 天后彻底删除。

### 4.3 工作台首页 `[P0]`

- **我的待办**：分配给我的生产任务和工单，按截止时间排序 `[P2]`。
- **最近图书**：显示封面、进度条（已完成章节 / 总章节）、最近修改时间。
- **进行中的 AI 任务**：实时显示进度，点击可跳到对应位置。
- **积分**：余额、本月消耗、即将过期的积分。
- **快捷入口**：新建图书、一键成书、快速配音、AI 设计音色、克隆我的声音。
- **公告与更新日志**。

### 4.4 图书管理

**新建图书** `[P0]`
- 三种方式：
  1. 上传书稿：支持 txt / docx / epub / pdf，单文件不超过 50MB、不超过 300 万字。
  2. 粘贴文本。
  3. 创建空图书。
- 文件编码自动识别（GBK / UTF-8），自动清洗（去掉广告行、多余空行，全角半角统一可选）。
- 上传后进入"智能拆章"确认页（见 4.5）。

**图书信息**
- 必填：书名、制作类型（单播有声书 / 多播有声书 / 广播剧）、语言。
- 选填：
  - 作者、原著或改编、简介、题材分类、标签。
  - 封面：手动上传、从 epub 提取，或 AI 生成 `[P3]`。
  - ISBN。
  - 系列 `[P2]`。
- 版权信息 `[P1]`：授权方、授权类型、授权期限、授权文件。发布前会检查。

**图书制作设置**
- 默认旁白角色、质量档（经济 / 标准 / 精品，决定默认的平台和模型路由）。
- 停顿规则（见 4.13.2）、响度标准、片头片尾模板、AI 内容标识开关（受平台策略约束）。
- 工作流模板 `[P2]`。

**剧组（图书成员）** `[P0 基础 / P2 岗位]`：从工作室成员中添加，或邀请外部协作者；为成员分配岗位；配音岗位的成员可以认领角色。

**图书列表**
- 卡片视图和列表视图。
- 可按状态、制作类型、负责人、标签筛选，支持搜索。
- 每本书显示：进度、总字数、已完成时长、角色数、积分消耗。

**图书状态**：筹备中 → 制作中 → 已完成 → 已发布；任何状态都可以转为已归档。

**其他操作**：
- 复制图书：可选复制画本和角色，不复制音频。
- 归档。
- 删除：进入回收站，30 天内可恢复。

**图书概览页**
- 进度矩阵：章节 × 工作流环节，用颜色表示状态，点击格子跳到对应任务。
- 统计：字数、预估时长和已完成时长、角色数、各角色台词量、积分消耗（按环节、平台）、工单数。
- 剧组成员及各自的工作量。

### 4.5 智能拆章与章节管理

**智能拆章** `[P0]`
- **章节识别**：
  - 先用规则识别"第 X 章 / 第 X 回 / Chapter N / 卷 X"等标题。
  - 规则识别不出来时，由 LLM 识别。
- **非正文识别**：识别版权页、目录、前言、序、后记、作者的话。默认不纳入制作，可以手动勾选纳入。
- **确认页**：
  - 左边显示原文，右边显示识别出的目录树。
  - 可以合并、拆分（在任意段落处切开）、重命名、勾选或取消。
  - 支持"卷 → 章"两级结构。
- **按字数重新拆分**：例如每 3000 字切成一集，切点落在最近的段落边界，章节名按规则自动生成，如"第 12 集"或"原章节名（上）/（下）"。这是为了适配音频平台按集发布的习惯。
- **追加导入（连载更新）**：上传新内容后自动识别新章节，追加到末尾 `[P1]`。

**章节管理** `[P0]`
- 列表字段：序号、标题、字数、预估时长、当前环节和状态、负责人、成品时长、更新时间。
  - 预估时长默认按 220 字/分钟计算，可在设置中修改。
- 操作：新增、编辑标题、拖拽排序、删除、批量操作（批量画本、批量生成、批量指派、批量导出）。
- **原文编辑**：
  - 修改原文后，系统用 diff 展示修改的位置。
  - 如果该章已有画本，提示"画本需同步"：只对改动的部分重新生成画本，未改动的片段保留。
  - 受影响的片段会被标为"待更新"（见 6.6）。

### 4.6 智能画本（核心）

#### 4.6.1 全书角色分析 `[P0]`
- 触发：首次生成画本前自动执行，也可以手动对全书或指定章节范围执行。
- 输出：
  - 角色列表，包含姓名、别名（如"林姑娘、黛玉、颦儿"会合并成同一个角色）。
  - 每个角色的类型：主角 / 配角 / 龙套 / 群演。
  - 角色小传：性别、年龄段、身份、性格、声音特征描述、首次出场章节、预估台词量。
  - 人物关系 `[P3]`。
- 用户在角色页确认、修改、合并后，结果作为后续画本的角色表。

#### 4.6.2 章节画本生成 `[P0]`
- 范围：单章、多章批量或全书。发起前显示字数和预估积分。
- 生成内容：

| 项 | 说明 |
|---|---|
| 片段类型 | 旁白 / 对白 / 内心独白 / 音效提示 / 停顿 |
| 说话人 | 归属到角色表中的角色，并附带置信度 |
| 情绪 | 统一情绪集：平静、开心、悲伤、愤怒、恐惧、惊讶、厌恶、温柔、紧张、疲惫、低语、喊叫…，加上强度（轻 / 中 / 强） |
| 表演标记 | 行内标记：`[笑]`、`[叹气]`、`[哭腔]`、`[气声]`、`[停顿]`… |
| 注音 | 多音字、生僻字、数字、英文、专有名词的读音 |
| 音效提示 | 仅广播剧模式：如"[音效：敲门声]" |

- **原文保真**：
  - AI 不改写正文。
  - 画本生成后，自动校验全部片段拼起来和原文一字不差；不一致时提示，并定位到出问题的位置。
- **广播剧模式**：
  - 可以选择去掉"他说道""她笑着说"之类的提示语。
  - 去掉的文本以删除线保留，方便对照和恢复。
- **未识别说话人**：生成"候选角色"，在编辑器里处理（合并到已有角色 / 新建角色 / 归为路人）。

#### 4.6.3 画本编辑器 `[P0]`
- **视图**：
  - 片段列表视图：默认视图，用虚拟滚动支撑上千个片段。
  - 原文对照视图：左边原文，右边片段，滚动同步。
- **片段操作**：
  - 改角色：下拉选择，或用数字快捷键 1–9 对应角色列表。
  - 在光标处拆分、与相邻片段合并、插入、删除、拖拽排序、复制。
- **片段属性**：
  - 情绪和强度、语速、音量。
  - 前停顿、后停顿：默认值来自停顿规则，可单独覆盖。
  - 表演指令：自由文本，用于支持指令控制的模型。
  - 注音：选中一个字，选择读音，或手动输入拼音。
  - 锁定：锁定后，重新生成画本或批量生成都不会覆盖。
- **批量工具**：
  - 批量改角色：选中多个片段改；或者"把本章所有 A 的台词改为 B"。
  - 查找替换：支持只替换文本，或同时修改 TTS 读音文本。
  - 全文批量标音：扫描全书某个字或词的所有出现，逐个或统一设定读音。
  - 批量设置情绪和停顿。
- **校对辅助**：
  - 低置信度片段高亮显示。
  - 筛选："只看待确认 / 只看某角色 / 只看有注音 / 只看已修改"。
- **统计**：本章各角色的台词句数、字数，以及预估时长。
- **版本** `[P1]`：
  - 每次 AI 重新生成画本都产生一个新版本。
  - 支持版本对比（差异高亮）和回滚。
  - 锁定的片段会自动带到新版本里。
- **编辑锁**：同一章节同一时间只允许一个人编辑，其他人只读并显示"某某正在编辑"。实时多人协同编辑放到 `[P3]`。
- **自动保存**：编辑停止 1 秒后自动保存，离开页面时检查是否还有未保存的内容。

#### 4.6.4 画本导入导出 `[P1]`
- 导出：
  - 全章演播稿（docx，每个角色用不同颜色标注）。
  - 分角色台词本（docx / xlsx，给真人 CV 用，带上下文和情绪提示）。
- 导入：按平台模板（xlsx）导入人工制作的画本。

#### 4.6.5 发音词典 `[P0]`
- 三级词典：平台级（管理端维护）、工作室级、图书级。
- 冲突时的优先级：片段注音 > 图书 > 工作室 > 平台。
- 词条字段：词条、读音（拼音或音标）、替换文本（兜底方案，例如用同音字替换）、备注。
- 画本生成时会预填图书词典：AI 提取书中的人名、地名、生造词、多音字，用户逐条确认。
- 在上下文中试听：播放词条所在的那一句。
- 修改词典后，提示受影响的已生成片段数，可一键重新生成。
- **纠错回流** `[P2]`：用户可以把词条"提交到平台词典"，管理端审核通过后合入平台词典。

### 4.7 角色管理与选角

#### 4.7.1 角色管理 `[P0]`
- **角色卡片**：头像（可 AI 生成 `[P3]`）、名称、别名、类型、性别、年龄段、小传、声音特征、台词句数和字数、配音方式（AI / 真人）、绑定的音色或 CV、颜色标识。
- **旁白**：
  - 每本书默认有一个旁白。
  - 支持多旁白，例如第一人称和第三人称视角分别用不同的旁白，或者男版、女版旁白。
- **操作**：
  - 新建、编辑。
  - 合并：A 的台词全部迁移到 B，A 的别名并入 B。
  - 删除：台词变为"未分配"。
- **群演音色池** `[P1]`：
  - 路人、群演角色可以从"群演音色池"自动分配音色。
  - 音色池按性别和年龄分组，同一章内轮换使用，避免听起来是同一个人。

#### 4.7.2 AI 选角 `[P0]`
- **候选推荐**：
  - 根据角色小传，为每个角色跨平台推荐 Top 5 候选音色。
  - 每个候选显示：平台、匹配理由、价格档位、支持的情绪。
- **用真实台词试听**：自动选取该角色在书中 3 句有代表性的台词（不同情绪），用候选音色试听。试听扣少量积分，每天有免费次数。
- **一键全员选角**：为所有尚未选角的角色自动绑定第一候选音色。
- **没有合适的音色**：跳转到 AI 设计音色，并用角色小传预填音色描述（见 4.8.3）。
- **角色级参数**：语速、音调、音量、默认情绪。这些参数覆盖音色的默认值，对整本书生效，保证角色前后一致。
- **冲突提醒**：两个主要角色用了同一个音色或很相似的音色时给出提醒。
- **更换音色**：
  - 弹窗提示"将影响 N 个片段，预计消耗 X 积分"。
  - 确认后，只把该角色已生成的片段标为"待更新"，不影响其他角色。
- **真人选角** `[P1]`：
  - 把配音方式设为"真人"，指派 CV 或开放认领。
  - CV 认领需要负责人确认。
  - 确认后自动生成该角色的录音任务。
- 选角结果可以导出为"选角表" `[P2]`。

### 4.8 音色库与 AI 音色

#### 4.8.1 音色库 `[P0]`
- **分区**：官方音色、工作室音色、我的音色、收藏。
- **音色卡片**：名称、试听、性别、年龄段、风格标签（如少年、御姐、大叔、播音腔、方言…）、语言、适用场景、支持的情绪和表演标记、来源平台、价格档位（积分 / 千字）、到期时间（适用于部分平台的克隆音色）。
- **筛选**：性别、年龄、风格、语言、平台、价格档、是否支持情绪。
- **语义搜索** `[P1]`：输入描述，例如"温柔的中年女性，有一点沙哑"，按匹配度排序。
- **试听**：
  - 默认用示例文本试听。
  - 自定义文本试听：扣少量积分，每天有免费次数。
  - 可指定情绪试听。
- **我的音色管理**：编辑信息、共享到工作室或取消共享、删除（同时删除第三方平台上的音色）、查看哪些图书和角色在使用该音色。

#### 4.8.2 个人音色与工作室音色 `[P0]`
- 每个人都可以拥有自己的音色（AI 设计或克隆），默认只有本人能用。
- 共享到工作室后，工作室成员都可以使用。原作者可以撤回共享；撤回后，已绑定该音色的角色会收到提醒。
- 工作室音色由管理员或制作人创建，属于工作室。

#### 4.8.3 AI 设计音色 `[P0 接口 / P1 体验完善]`
1. 输入描述，覆盖性别、年龄、音色质感、语气、口音、适用角色等。平台提供描述模板和示例，也可以从角色小传一键带入。
2. 选择平台（只列出支持音色设计的平台）。
3. 生成 3 个候选并试听；可以修改描述后再生成。
4. 选中一个保存：命名、打标签、选择归属（个人 / 工作室）。

#### 4.8.4 声音克隆 `[P1 快速克隆 / P3 专业克隆]`
- **档位**：

| 档位 | 样本时长 | 说明 |
|---|---|---|
| 快速克隆 | 10 秒 – 2 分钟 | 训练快，相似度中等 |
| 专业克隆 | 30 分钟以上 | 需要较长训练时间，相似度和稳定性高 |

- **样本**：
  - 上传音频，或在线录制（平台提供朗读文本）。
  - 质量检测：时长、底噪、混响、是否有多人声、音量是否过低或爆音，并给出改进建议。
  - 可选自动降噪。
- **授权（必须完成）**：
  - 本人声音：朗读一段随机验证句（voice captcha），系统比对样本声纹 `[P3]`，通过后才能提交。
  - 他人声音：上传被克隆人的授权书和身份信息，进入管理端人工审核；审核通过后才能训练。
- **流程**：提交 → 训练中 → 可用 / 失败。完成后发通知。
- **平台差异**：部分平台的克隆音色有有效期，或者长期不用会失效。界面显示到期时间，到期前 3 天提醒。
- **试听比对**：原始样本和克隆结果并排试听。

#### 4.8.5 音色微调 `[P3]`
- 基于已有音色，用自然语言调整（例如"更年轻一些""语速慢一点"）或调节参数，生成一个新的音色变体。仅限平台支持的情况。
- 官方精调音色：在平台音色的基础上加一组固化参数，由管理端维护（见 5.4）。

#### 4.8.6 多平台支持 `[P0 接口预留]`
- 支持的平台：阿里（百炼 / CosyVoice）、MiniMax、火山引擎（豆包）、ElevenLabs、OpenAI、自部署模型（CosyVoice / IndexTTS 等）。各平台的具体接口暂不实现，开发期用 mock 平台跑通全流程。
- 每个音色属于一个平台。界面上的参数统一呈现，平台不支持的能力置灰并说明原因。
- **BYOK** `[P2]`：
  - 工作室可以配置自己的平台密钥，并选择"优先使用自有密钥"。
  - 用自有密钥调用时不扣 AI 积分，只按管理端配置收取平台服务费（可以为 0）。
  - 密钥加密存储，只显示末 4 位，可测试连接。
- 同一个功能可以有多个平台，由管理端的路由策略决定主备（见 5.6）。

#### 4.8.7 声音市场 `[P4]`
- CV 可以把个人音色上架为"可授权音色"，设定授权范围（仅试听 / 可商用）和单价。
- 其他工作室使用时，额外扣积分，按比例分给 CV，可提现。
- 上架需要实名，并通过本人声音授权验证。

### 4.9 AI 配音生成 `[P0]`

- **生成范围**：整章、多章批量、按角色（"只生成某个角色"）、选中片段、仅未生成的、仅待更新的。
- **生成前确认**：字数、预估积分、预估时长、各平台的用量分布，以及积分余额是否足够。
- **执行**：
  - 按角色分组并发生成。
  - 片段状态实时更新，可以随时取消。
  - 已完成的片段立即可以试听。
- **片段状态**：未生成 / 排队中 / 生成中 / 已生成 / 失败 / 待更新 / 已锁定。
- **播放**：
  - 单句播放。
  - 从当前位置连续播放：遇到未生成的片段时，可选择跳过或"边播边生成"（提前预生成后面几句）。
  - 倍速播放。
  - 播放时画本同步高亮。
- **生成历史（Take）**：
  - 每个片段保留所有生成版本，标明时间、音色、参数。
  - 可以试听对比、选定使用版本、删除。
- **重新生成**：
  - 同参数重新生成（得到不同的演绎）。文本、音色、参数都不变时，每个片段有 2 次免费重生。
  - 修改参数后再生成。
  - 在多个 Take 里挑一个。
- **表演控制**：
  - 情绪和强度、语速、表演标记、表演指令。
  - 平台不支持的控制项会给出提示：降级为指令文本，或者忽略。
- **参考演绎（Actor Mode）** `[P3]`：录一句自己的演绎，转换成角色音色，保留原来的语气和节奏（需要平台支持变声能力）。
- **自动质检**（默认开启，可关闭）：
  - 生成后用 ASR 回听，与文稿比对。
  - 不一致时自动重试，最多 2 次，不额外扣费。
  - 仍不通过的片段标为"疑似问题"，进入审听问题列表。
- **失败处理**：
  - 显示失败原因：平台错误、内容审核拦截、超时、积分不足。
  - 可一键重试，或切换到备用平台的相近音色重试 `[P2]`。
- **增量更新（智能重绘）**：
  - 原文、画本、音色、词典发生变化时，只有受影响的片段变为"待更新"。
  - 没有变化的片段直接复用缓存，不重复扣积分。

### 4.10 真人录音 `[P1]`

- **我的台词（CV 工作台）**：
  - 汇总我认领的所有角色台词，按图书、章节分组。
  - 筛选：待录 / 已录 / 返修 / 已通过。
  - 每句显示：前后各 2 句的上下文、情绪提示、注音、导演备注、相关工单。
- **在线录音**：
  - 选择麦克风，显示输入电平。
  - 录音前 3 秒倒计时（可关闭）。
  - 逐句录制，快捷键：空格开始/停止、回车下一句、R 重录、P 回放。
  - 录完自动切掉首尾静音，显示波形预览。
  - 一句可以录多遍，每遍都保留为一个 Take，选其中一遍使用。
- **实时质量提示**：音量过低、爆音、底噪过高、录音内容与文本不符（快速 ASR 校验）。
- **参考音**：可以播放 AI 生成的版本作为演绎参考，制作人可以关闭这个功能。
- **上传录音**：
  - 单句上传：直接作为该片段的 Take。
  - 整章长录音上传：进入智能对轨（见 4.11）。
- **音频规格**：浏览器录音以无损格式上传，服务端统一转为 48kHz / 24bit WAV 保存。
- **提交**：一章录完后提交，对应的生产任务流转到下一个环节（见 4.15）。
- **移动端录音** `[P3]`：H5 页面支持逐句录音（需要 HTTPS）。

### 4.11 智能对轨 `[P1]`

- **输入**：章节的长录音，支持 wav / mp3 / m4a。可以传多个文件，按顺序拼接；单个文件不超过 2 小时，支持断点续传。
- **两种模式**：
  - 全章模式：录音包含该章所有角色。
  - 单角色模式：录音只包含某个角色的台词（CV 把自己的台词连续录完），只匹配这个角色的片段。
- **处理流程**：
  1. ASR 转写，带逐字时间戳。
  2. 文本对齐到画本。
  3. 自动切片，生成 Take（来源标记为"真人"），并设为选中。
- **结果页**：
  - 每个片段显示匹配置信度，低置信度的高亮。
  - "多余音频"列表：废录、闲聊、重复的段落，可以试听，可以手动分配给某个片段。
  - "未匹配片段"列表：即漏录的句子。可以一键生成补录任务，或改用 AI 生成。
  - 重复录制：同一句录了多遍时自动识别，默认取最后一遍，可切换。
  - 切点微调：在波形上拖动边界，实时试听。
- **批量对轨**：多章排队处理，完成后发通知。

### 4.12 智能审听与质检

#### 4.12.1 智能审听 `[P1]`
- **触发**：手动触发，或进入"审听"环节时自动执行。
- **范围**：章节中每个片段被选中的 Take（AI 生成的和真人录的都检查）。
- **检测项**：

| 类别 | 检测项 |
|---|---|
| 文本 | 漏读、多读、错读（字词不同）、读音可疑（多音字和注音不符） |
| 节奏 | 停顿过长或过短、语速异常、片段内长时间静音 |
| 音质 | 音量异常、爆音或削波、底噪过高、口水音或喷麦 `[P3]` |

- **结果**：
  - 在片段上打问题标记，生成问题列表。
  - 点击问题可以定位播放，高亮到具体的字。
- **处理**：
  - 一键把问题转为工单（可以设置为自动转工单）。
  - 误报可以标记"忽略"，忽略记录用于优化检测模型。

#### 4.12.2 人工审听 `[P1]`
- **审听视图**：
  - 按成品方式连续播放（含后期效果），文稿同步滚动高亮。
  - 随时打点：按快捷键 M，在当前时间点创建工单或批注，选择问题类型、填写描述、指派处理人。
  - 显示审听进度（已听时长 / 总时长）。
- **结论**：通过，或打回（打回时必须附带工单）。
- 审听通过率、返修率计入统计（见 4.16）。

#### 4.12.3 成品技术检测 `[P1]`
- 检测项：整体响度（LUFS）、真峰值、底噪、采样率、码率、首尾静音时长。
- 对照所选平台预设（喜马拉雅、Spotify、ACX 等，参数由管理端维护）给出是否达标。
- 不达标的项可以一键修复，例如重新做响度标准化。

#### 4.12.4 质检报告 `[P2]`
- 章节或全书的问题统计：按类型、角色、CV。
- 可导出为报告，交给版权方作为验收材料。

### 4.13 后期制作

#### 4.13.1 自动合成 `[P0]`
- **按画本自动合成对白轨**：
  - 按顺序拼接每个片段选中的 Take。
  - 应用停顿规则和片段级停顿。
  - 每句做响度预归一。
- **自动应用效果**：
  - 内心独白片段自动加轻微混响（可在图书设置中关闭）。
  - 音效提示点按推荐放置音效素材 `[P3]`。
- **渲染成品**：
  - 混合对白、BGM、音效。
  - 做整体响度标准化。
  - 加上片头片尾。
  - 按导出设置输出。

#### 4.13.2 停顿规则 `[P0]`

| 场景 | 默认值（可在图书设置中修改） |
|---|---|
| 同一角色连续说话 | 300ms |
| 换说话人 | 500ms |
| 换段落 | 800ms |
| 场景切换（空行、分隔符） | 1500ms |
| 章节开头 / 结尾留白 | 1000ms / 2000ms |

#### 4.13.3 多轨时间轴 `[P1]`
- **轨道**：对白轨（按画本自动生成，可展开成每个角色一轨）、BGM 轨、音效轨、环境音轨、片头片尾轨；可以自己添加轨道。
- **编辑**：
  - 拖动、裁剪、分割、复制、删除、吸附。
  - 横向缩放，显示波形。
  - 撤销 / 重做。
  - 音量包络、淡入淡出。
  - 直接拖动对白之间的间隙来调停顿，结果会回写到片段的停顿属性。
- **素材**：从资产库拖入。
- **BGM**：循环铺满、自动闪避（有对白时 BGM 自动降低，默认 -12dB，可调）、淡入淡出。
- **实时预览**：前端实时混音试听，不需要渲染。
- **与画本联动**：在时间轴上选中一个对白片段，会定位到画本里的那一句；画本改动后，时间轴自动更新，手动调整过的部分保持不变。

#### 4.13.4 效果器 `[P1 基础 / P3 增强]`
- 可以加在片段级或轨道级。
- 预设效果：降噪、电话音、对讲机或广播、回声和混响（房间 / 大厅 / 空旷 / 山谷）、内心独白、变调、均衡。
- 全局处理：响度标准化（按平台预设）、限幅；去齿音、去口水音 `[P3]`。
- 效果预设可以保存到资产库，在团队内复用 `[P2]`。

#### 4.13.5 片头片尾 `[P1]`
- 模板由片头音乐、AI 播报和声明组成。
- 播报文本支持变量：`{书名}{作者}{章节号}{章节名}{主播}{出品方}`。
- 可以包含 AI 生成内容声明（受平台合规策略约束，见 5.10）。
- 模板可以挂在图书上，渲染每一章时自动套用；也可以保存到资产库复用。

#### 4.13.6 工程导出 `[P2 分轨 / P4 AAF]`
- 分轨导出（stems）：每个角色、BGM、音效各一轨。
- 时间轴工程：P2 用 JSON 格式；P4 支持 AAF，方便导入 Audition、Pro Tools 等专业软件。

### 4.14 资产库

- **分类** `[P0]`：音色（见 4.8）、背景音乐、音效、环境音、片头片尾模板 `[P1]`、效果预设 `[P2]`、图片。
- **来源分区**：官方（平台提供的免费素材）、工作室、个人。
- **素材属性**：名称、分类、标签、时长、格式、采样率、授权类型（可商用 / 仅限平台内使用 / 需署名）、来源（上传 / AI 生成 / 官方）、上传人、被引用次数。
- **上传** `[P0]`：
  - 批量上传。
  - 自动提取时长和波形，统一转码。
  - 用文件 hash 去重。
  - 自动建议标签 `[P2]`。
- **搜索**：按分类、标签、时长范围搜索；语义搜索 `[P2]`，例如输入"雨夜，远处有雷声"。
- **预览**：波形播放，支持循环播放。
- **AI 生成音效** `[P1]`：输入描述，生成 4 个候选（每个不超过 20 秒），可以保存到资产库。
- **AI 生成配乐** `[P3]`：指定风格、情绪、时长、是否可循环。已接入 Suno（经 New API / One API 等中转服务）：可选纯音乐或带人声的歌曲，可填风格、歌名和歌词，每次生成两首；时长由 Suno 决定。
- **使用管理**：
  - 收藏。
  - 查看引用位置。
  - 删除被引用的素材时提示，可选"替换为其他素材"。
- **存储配额**：按套餐限制，显示已用空间，超出时禁止上传。

### 4.15 生产管理（协作）`[P2]`

#### 4.15.1 工作流模板
- 内置三个模板：

| 模板 | 环节 |
|---|---|
| AI 多播 | 画本 → AI 配音 → 后期 → 审听 → 完成 |
| 真人精品 | 画本 → 真人录音 → 对轨 → 后期 → 审听 → 完成 |
| 人机混编 | 画本 → 配音（按角色分别走 AI 或真人）→ 后期 → 审听 → 完成 |

- 自定义模板：增删、排序、命名环节；设置每个环节是否需要审核、默认负责人、默认工期。
- 模板在工作室级维护，每本图书选用一个，图书内可以微调。

#### 4.15.2 生产任务
- **任务单元**：章节 × 环节。配音环节会进一步拆成"章节 × 角色"，每个 CV 只负责自己的角色。
- **字段**：环节、负责人、状态、截止时间、计量（字数或成品时长，用于计薪）、关联工单数。
- **派发方式**：
  - 手动指派。
  - 批量指派：选多章，一次指给一个人。
  - 自动派发：配音任务按角色认领关系自动派给 CV；其他环节派给该环节的默认负责人。
- **流转**：
  - 负责人点击"完成"后：如果该环节需要审核，进入"待审核"；否则自动流转到下一环节，并通知下一环节的负责人。
  - 打回：必须写原因或关联工单，任务退回到指定的上游环节。
- **截止提醒**：到期前 1 天提醒负责人；逾期后同时提醒负责人和图书负责人。

#### 4.15.3 看板
- 图书进度矩阵：章节 × 环节。
- 我的任务看板：按状态分列（待开始 / 进行中 / 待审核 / 已完成）。
- 成员工作量：每人手上进行中的任务数和字数，用于派单时平衡负载。
- 截止日期视图（日历或甘特图）`[P3]`。

#### 4.15.4 评论
- 可以定位到片段（画本中）或时间点（审听、时间轴中）。
- 支持 @成员、回复、标记解决。
- 所有沟通都留痕。评论可以一键转为工单。

#### 4.15.5 工单
- **来源**：人工审听、智能审听、评论转化、CV 自查。
- **类型**：漏读、错读、多读、读音、情绪 / 演绎、噪音 / 音质、剪辑、画本错误、其他。
- **字段**：片段、时间点、类型、描述、附件（可以录一段语音示范）、处理人、复核人、状态。
- **状态**：待处理 → 处理中 → 待复核 → 已关闭；处理人可以驳回（认为不是问题），驳回后由复核人裁决。
- **处理闭环**：
  1. 处理人重新生成或重录对应片段。
  2. 系统自动关联新的 Take。
  3. 复核人试听新旧版本对比。
  4. 复核人确认后关闭工单。
- **工单列表**：按图书、章节、类型、处理人、状态筛选。

#### 4.15.6 变更传播与提醒
- 原文改动：通知画本负责人。
- 画本改动：已生成或已录的片段标为"待更新"，并通知对应的 CV 或生成负责人。
- 已经进入审听或已完成的章节发生改动时，提示"将使该章退回到某某环节"，需要确认。

#### 4.15.7 分享审听链接
- 为章节或整本书生成只读审听链接，用于给作者、版权方试听。
- 可设置：有效期、访问密码、是否允许评论（对方可以匿名填一个昵称）、是否允许下载。
- 外部评论汇总到图书评论中，可以转为工单。
- 链接可以随时撤销。

#### 4.15.8 操作日志
- 图书内的关键操作全部记录：画本修改、选角、生成、录音提交、流转、导出。
- 日志可筛选、可追溯。

### 4.16 统计与计薪 `[P2]`

- **个人统计**：我完成的任务数、字数、成品时长；按日、周、月统计。
- **团队统计**：成员工作量、产能（字 / 天）、审听一次通过率、返修率、平均返修时长。
- **成本统计**：图书的积分消耗（按环节、平台、角色），单位成本（积分 / 万字），并与图书预算对比。
- **计薪**：
  - 单价配置：
    - 可以按环节设置，计量单位是每千字、每分钟成品时长或每集。
    - 可以按成员或角色单独覆盖，例如主角 CV 用更高的单价。
  - 计薪规则：只有状态为"已完成"的任务计入；返修不重复计量；可配置扣减项，例如每张审听工单扣多少 `[P3]`。
  - 结算周期：选定时间范围生成薪酬报表（成员 × 任务 × 计量 × 单价 = 金额），可以导出 Excel。
  - 结算状态：可以标记为未结算或已结算，已结算的任务会锁定。
- 计薪只是工作室内部的统计工具，平台不参与资金流转。声音市场的分成除外，见 4.8.7。

### 4.17 成品管理、导出与分发

#### 4.17.1 成品管理 `[P0]`
- 每章的最新成品：版本、时长、渲染时间、技术检测结果、状态（未渲染 / 已渲染 / 已过期，过期指画本或时间轴在渲染后又有改动）。
- 渲染历史：保留最近 5 个版本，可以试听、可以回滚。

#### 4.17.2 导出
- **格式**：
  - MP3（128 / 192 / 320 kbps）`[P0]`。
  - WAV（44.1kHz 或 48kHz，16bit 或 24bit）`[P0]`。
  - M4A / AAC `[P1]`。
  - M4B：整本书一个文件，带章节标记和封面 `[P1]`。
- **范围**：单章、多章、整本书（单个文件，或按章打成 ZIP）。
- **附带内容**：
  - 字幕或带时间戳文稿（SRT / LRC / JSON），可用于播放器文字同步 `[P1]`。
  - 分轨 `[P2]`。
  - 画本和台词本 `[P1]`。
  - 元数据（ID3：书名、作者、主播、封面、ISBN、章节号）`[P0]`。
- **平台预设** `[P1]`：一键套用喜马拉雅、Spotify、Apple Podcasts、ACX 等平台的参数（响度、格式、码率、首尾静音）。参数由管理端维护。
- **命名规则**：可配置，默认是 `{序号}_{章节名}`。
- 尚未生成或未渲染的章节，导出时提示"自动生成并消耗积分"。

#### 4.17.3 分发 `[P4]`
- 平台账号绑定：通过平台开放接口授权。
- 一键同步上传、定时发布（连载更新时按计划逐集上线）、发布状态回传。
- RSS Feed：用于播客式分发（Spotify、Apple Podcasts 等）。
- **发布前检查**：元数据是否完整、技术指标是否达标、AI 内容标识、版权授权是否在有效期内。
- **平台政策提示**：在发布页说明各平台对 AI 有声内容的政策。例如，据第三方报道，Audible 的 ACX 不接受第三方工具生成的 AI 音频，以平台官方规则为准。
- **公开试听页** `[P3]`：生成作品的公开播放页和嵌入播放器，方便作者推广。

### 4.18 一键成书（全自动流水线）`[P3]`

1. **上传书稿**：同 4.4，可以一次上传多本，排队处理。
2. **选择配置**：
   - 制作类型：单播 / 多播 / 广播剧。
   - 质量档：

| 质量档 | 平台和模型路由（具体规则由管理端配置） |
|---|---|
| 经济 | 旁白和群演走低成本或自部署模型 |
| 标准 | 主要角色走主流模型 |
| 精品 | 主要角色走高表现力模型，并开启更严格的自动质检 |

   - 旁白：指定音色，或交给 AI 自动选择。
   - 后期：是否加 BGM、片头片尾模板、响度标准。
   - 人工确认点（可选）："选角后暂停，等我确认"。
3. **预估**：字数、积分（冻结）、预计耗时。确认后开始。
4. **自动执行**：拆章 → 角色分析 → 画本 → 选角 → 配音 → 自动审听与重试 → 后期 → 成品。
5. **进度页**：
   - 显示各阶段进度和逐章进度。
   - 已完成的章节可以先试听。
   - 可以随时暂停或取消；取消时，已消耗的积分按实际用量结算，没用完的退还。
6. **完成**：
   - 生成完成通知。
   - 图书自动进入标准制作台，用户可以局部精修，修改后只重新生成受影响的部分。
- **批量队列**：B 端可以提交多本书排队，设置优先级，查看整个队列的状态。

### 4.19 快速配音 `[P1]`
- 不需要建图书，直接输入短文本（不超过 5000 字）。
- 选择音色、情绪、语速后生成，可以试听和下载。
- 支持简单的多人对话：按"角色名：台词"的格式输入，为每个角色选音色，一次合成。
- 保留历史记录（30 天），可以把一次结果转为新图书。

### 4.20 任务中心与通知

- **任务中心** `[P0]`：
  - 列出所有 AI 异步任务：画本、角色分析、生成、对轨、审听、渲染、导出、克隆、一键成书。
  - 显示状态、进度、耗时、积分、失败原因。
  - 支持重试、取消，以及跳转到相关位置。
- **站内通知** `[P0]`：AI 任务完成或失败、积分不足。
- **站内通知** `[P1]`：音色训练完成、音色即将到期、成员邀请、认领审批。
- **站内通知** `[P2]`：任务分配、流转、打回、截止提醒、工单、评论 @。
- **其他渠道**：邮件、短信（只用于重要事件）、浏览器推送，用户可在偏好中分别开关 `[P2]`。

### 4.21 计费与积分

- **积分**：所有 AI 能力统一扣积分。积分分两类：
  - 套餐积分：每月发放，可以结转到下个月，最多结转 1 个月、不超过月度额度的 2 倍。
  - 充值积分：12 个月有效。
  - 扣积分时先扣即将过期的。
- **套餐（示例，价格和内容由管理端配置）**：

| 套餐 | 定位 | 主要差异 |
|---|---|---|
| 免费版 | 体验 | 每月少量积分；MP3 128k 导出；不能商用；1 个席位；最多 3 本图书 |
| 个人版 | 个人创作者、CV | 更多积分；高品质导出；可商用；快速克隆；1 个席位 |
| 团队版 | 工作室 | 多个席位；真人链路（对轨、审听）；生产管理与计薪；BYOK |

- **扣费流程**：发起任务时预估并冻结积分 → 完成后按实际用量结算 → 失败或取消的部分退还。
- **余额不足**：发起前拦截；如果任务执行中余额耗尽，暂停任务并通知，充值后可以继续。
- **额度控制** `[P2]`：管理员可以为成员或图书设置积分上限，超出后需要审批。

  - 充值订单、套餐订单。

- **支付** `[P3]`：国内用微信支付、支付宝；海外用 Stripe。P0 阶段由管理端手工发放积分。

### 4.22 开放平台 `[P3]`

- **API Key 管理**：创建、命名、设置权限范围（只读 / 制作 / TTS）、IP 白名单、限流、禁用、轮换。

- **Webhook**：任务完成或失败时回调，带签名校验，失败按策略重试，保留投递日志。

## 6. 核心业务流程

### 6.1 AI 多播有声书（精品工作台）
1. 新建图书，上传书稿，确认智能拆章结果。
2. 执行全书角色分析，确认角色、合并别名。
3. AI 选角：用真实台词试听候选音色，绑定音色；没有合适的就 AI 设计一个。
4. 生成第 1 章画本，校对角色、情绪、注音，确认图书发音词典。
5. 生成第 1 章配音，自动质检。试听，对不满意的片段重新生成或调整。
6. 自动合成，在时间轴上加 BGM 和音效，渲染成品。
7. 审听：智能审听加人工审听，修复问题。
8. 第 1 章确认后作为"样章"定下风格，其余章节批量执行画本 → 配音 → 合成。
9. 导出成品，或分发到平台。

### 6.2 人机混编（主角真人，其余 AI）
1. 选角时把主角设为"真人"，指派 CV；旁白、配角、群演用 AI。
2. 画本确认后，系统自动为 CV 生成录音任务，同时生成 AI 角色的配音。
3. CV 在"我的台词"里逐句录音，或者整章连录后上传，由智能对轨切片。
4. 真人和 AI 的 Take 在同一条对白轨中自动合成。
5. 后期 → 审听 → 工单返修（CV 补录，或 AI 重新生成）→ 完成。

### 6.3 一键成书
上传 → 选择配置 → 预估并冻结积分 → 无人值守全流程 → 逐章可听 → 完成通知 → （可选）进入制作台精修。

### 6.4 审听返修闭环
1. 智能审听或人工审听发现问题，生成工单并指派给处理人（CV 或生成负责人）。
2. 处理人重录或重新生成，新 Take 自动关联到工单。
3. 工单进入"待复核"，审听人对比新旧版本。
4. 复核通过则关闭工单；不通过则退回给处理人。
5. 章节的所有工单都关闭后，审听人点击"通过"，章节完成。

### 6.5 声音克隆
1. 选择档位，上传或录制样本，通过质量检测。
2. 授权：本人声音朗读验证句；他人声音上传授权材料，等待人工审核。
3. 选择平台，提交训练，训练完成后发通知。
4. 试听比对，保存为个人音色，可以共享到工作室。
5. 音色到期前提醒；用户可以续期（如果平台支持）或重新克隆。

### 6.6 原文变更传播
1. 修改章节原文后，系统计算 diff。
2. 画本中受影响的片段标为"需同步"，画本负责人收到通知。
3. 只对改动部分重新生成画本，锁定的片段不动。
4. 文本发生变化的片段，其音频变为"待更新"：AI 片段可以批量重新生成；真人片段生成补录任务。
5. 如果章节已经进入审听或已完成，提示章节将退回到对应环节，需要确认。

## 7. 状态定义

| 对象 | 状态流转 |
|---|---|
| 图书 | 筹备中 → 制作中 → 已完成 → 已发布；任何状态都可以转为已归档 |
| 章节 | 由工作流驱动，状态 = 当前环节 + 环节状态，例如"配音 · 进行中"。所有环节都完成后为"已完成"，发布后为"已发布" |
| 片段（音频） | 未生成 → 排队中 → 生成中 → 已生成 / 失败。已生成的片段因文本、音色、参数变化变为待更新。真人片段另有：待录 → 已录 → 返修中 → 已通过 |
| 生产任务 | 待开始 → 进行中 → 待审核 → 已完成；待审核可以转为已打回，再回到进行中 |
| 工单 | 待处理 → 处理中 → 待复核 → 已关闭；处理人驳回后进入待裁决，裁决结果为关闭或退回处理中 |
| 音色 | 审核中（仅他人授权）→ 训练中 → 可用 / 失败；可用之后可能变为即将到期、已过期，或被停用（管理员下架） |
| AI 任务 | 排队中 → 运行中 → 成功 / 失败 / 已取消；失败可以重试回到排队中；一键成书还有"已暂停" |
| 成品 | 未渲染 → 渲染中 → 已渲染；渲染后又有改动则为"已过期" |

## 11. 待确认事项

1. **首发市场**：国内、海外，还是同时上线？这会影响登录方式、支付、合规要求、默认接入的平台，以及界面默认语言。
2. **首批接入的平台**：LLM、TTS、ASR 各先接哪一家？这决定 P0 和 P1 的实际效果和成本底线。
3. **MVP 先面向谁**：先面向个人创作者（P0 → P3 一键成书提前），还是先面向工作室（P0 → P1 → P2）？这决定 P1 和 P2 谁先做。
4. **私有化部署**：是否有明确的首个客户？有的话，需要提前评估自部署 TTS 和 LLM 的效果。
5. **定价**：需要拿到上游平台的实际单价，算出每万字成本，再确定积分单价和套餐。
